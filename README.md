🚀 **Power BI Project: Blinkit Sales Analysis Dashboard**

I'm excited to share my Power BI dashboard project, where I explored sales data to uncover meaningful business insights using interactive visualizations.

📊 **Key features:**
• KPI cards for Total Sales, Average Sales, Number of Items, and Average Rating  
• Interactive filters for Outlet Location Type, Outlet Size, and Item Type  
• Sales trends by Outlet Establishment Year  
• Analysis of outlet sizes, outlet locations, and item categories  
• A consolidated dashboard for exploring sales performance  

🛠️ **Tools Used:** Microsoft Power BI, Data Visualization, Data Analysis

This project helped me practice dashboard design, data visualization, and presenting data in a way that makes business performance easier to understand.

I'm looking forward to building more projects and continuously improving my data analytics skills! 📈
